# 专业造景与直播布局
## 从参考到创意
先识别产品的形态、材料、使用情境、产地与主情绪，选择一个场景命题。再拆解参考的主锚点、骨架、围合、高低进深、地面衔接和光线；继承这些关系，不只取最醒目的门框或复制原广告。
内部快速比较2—3条适用路线，按主题匹配、参考美感、可直播、真实建造与批量差异选定，不增加用户选方案步骤。记录主命题、选择依据、结构语法、群组位置、站位、色材和焦平面。
主形态有节制地延伸到建筑、家具或地面中的两三个载体，以尺度与进深变化呼应；不要每个角落复制同一符号。

| 路径 | 可迁移的机制 | 判断边界 |
|---|---|---|
| 产品形态转建筑 | 提手、杯沿、果实切面或折页变为入口、檐口、隔断、模块 | 巨物是主题装置，正常产品/家具保持实尺度；不是所有品类都巨型包装 |
| 连续框景 | 前后门洞、景窗及透空立面形成层次 | 框架接入场地，有支撑与可用入口，不只孤立门框 |
| 店面/功能亭 | 局部立面、遮篷、陈列窗、柜台与外摆共同成系统 | 不造无用完整商店，不让远处小亭替代近中景展示 |
| 重复几何 | 拱片、肋片、格栅、圆孔、嵌套轮廓形成节奏 | 结构已丰富时不再塞摆件；避免构件堵动线 |
| 使用情境 | 家具、织物、陈列设备和借景构成生活群组 | 物件与产品使用有关，不自动套米白客厅 |
| 悬挂轻围合 | 梁架、织物、遮篷或花艺补足上层体量 | 支撑可信，避开主播头部/视线，不默认繁花满顶 |
| 地景/产地 | 低地台、场地边界、原料组与景观表达来源 | 地景不占站位，不每套同树同庭院；不虚构产地认证 |
| 运动设施 | 场地线、网架、收纳、补给亭提供功能语法 | 仅品类匹配使用，网格不是通用背景 |

## 先判断直播方式
参考的人不用于生成，但其尺度、姿态与遮挡可帮助判断布局；忽略人物形象不能忽略使用方式。
- 全身站播/服装：保留完整连续站位面、横移及转身空间。低道具靠侧前缘，衣架/展示群组错位向侧后，避免遮住服装和腿部。
- 产品柜台后直播：中景台面可以遮挡下身，台高/台深要与成人操作和产品展示匹配；不能把此布局泛化为全身站播。
- 坐播/试吃/休闲：坐具、桌面、手部操作关系是核心，允许桌面遮挡腿；别为套用站播而删掉功能桌椅。
- 产地/外景：主题路径、可站地面和展示平面必须成立，水、起伏草地或不可走地景不得代替站位。
人数/方式未指定时可依据参考推断并记录，只有影响结果的关键冲突才澄清。最终仍无人。

### 首轮落实人物承载与前景
未指定人数时默认考虑双人使用，明确两人的位置、姿态、操作及进出空间。人物承载不等于每套都摆两椅加圆桌；按品类和主题选站立操作台、横向展示长桌、长凳、沙发坐播/半躺、草垛坐席等，景区宣传也可用湖中木舟等主题相符的承载方式。造型和摆放关系随空间设计，不把示例或上一套的家具固化为模板，也不为变换形式添加无关物件。
这些关系必须从第一轮写入提示词。坐播检查桌椅高度、膝部空间、伸手操作与起身路径；站播检查双人连续站位和动作空间。无人画面仍应明确体现人物如何使用场景。若前景地面过长或光秃，先调整机位、前中景比例和功能布局，可加入适合的承载设施，不能用无关杂物填空，也不能等待第二轮修复已知的空旷问题。
首轮先估计两位主播的身体、座席及操作范围是否处于中心80%保守区，结合成人比例与镜头距离规划。座椅或有效坐席贴边须调整，横向长桌两端可以合理出画；不要为了完整台沿缩窄舒展长台，或拉远导致大片地面。近镜头功能组的台面投影与前脚/基座要共同安排，底部仅保留符合姿态的地面余量。具体裁切与前景检查见workflow.md。

## 空间丰富而不拥挤
组织主骨架、上层/侧翼、中景展示、低位地面衔接和后景；不要求每层各增加一件物体。群组内部用高低、大小、错位和少量遮挡，群组之间留安静面。
至少区分主播/展示层与侧后造景层，有前景时进一步拉开距离。不要把所有篮箱、植物、台面和凳子排在中景同一横线，中央只剩一条缝。通道可走不等于两人能站、操作或转身。
植物用于围合、边界、轮廓或产地表达，而非填满空白；柜台和后退陈列也能形成层次。减少拥挤优先重排进深、减重复群组，不把舞台整体清空。
地面可用台地、地毯、拼接、曲线边界或柔和投影连接结构。复杂材质纹理不承担空间丰富度。简洁立面、重复拱片、透空屏风也能专业成立。

## 前景字与主播遮挡（仅用户要求时）
先确定主播脚点和匿名成人投影，再安排地面字，不以“文字可读/没裁切”替代功能检查。字高依据参考相对成人的比例、站位距离、镜头投影判断，不固定所有场景40—50cm或同一画幅百分比。
全身站播时字通常靠前缘、低于膝部且尽量只遮脚踝/小腿下段，基座不放在脚点或转身区，侧边可绕行；若用户要高字或别的布局，明确评估其遮挡。文字不是跨满宽度的围栏，不机械固定中心80%占满。
逐字核对内容、字体设计和统一基线。用户要直立字时正面垂直、方向一致，无斜体、倾倒、扭转或各字歪斜；3D侧厚与透视不等于字面可歪。透明薄牌、低台阶字、独立雕塑字按当次需求选择，不全做成巨大书法橙色厚字。
无人物交付也须在review写出脚点、估计成人高度、遮挡范围和站位连续性的观察依据；若无法判断，不称完全合格。

## 实景、景片与摄影
先判断参考是实景、搭建、绿幕、平面景片、概念图还是屏幕贴片。原理可借鉴，但不照抄悬浮结构、无支撑、尺度错误、曝光异常或全图过锐。
横向快闪转竖幅时重排主建筑、相关陈列与局部动线，不能简单裁掉支持主创意的侧翼，也不能拉远到产品变小点。平面贴片和可建空间不能混为一谈；默认真实搭建摄影。
实体强色面可保留，不强改全部米白木色；产品与中性色不受全图滤镜污染。低频轮廓/体量/光影建立丰富度，局部细节只用于必要产品识别。真实远景按距离失焦，同平面画面与标识遵循物理焦距。
提示词按“完整舞台与机位—结构—群组位置与进深—站位与地面—产品资产—色材光线景深”组织，不只列物品，不堆互相矛盾的百分比。

## 批量差异与第二轮
先列矩阵：主题、创意路径、骨架轮廓、主装置、地面、陈列组织、材料、配色、光线。相同原料可以通过使用情境、建筑、材料或少量原料表达，不能只换logo/颜色/树种。共同元素由用户指定时保留，以其他维度拉开差异；不添加无关东西求不同。
首轮争取交付水准。第二轮依据实际验收：缺结构补结构、缺进深重排、占站位调整体量与脚点、过锐调摄影；不将所有问题归为加道具或删道具。参考优点、成立轮廓与群组应保留，真实局限须报告。
