# 专业造景与直播布局
## 从参考到创意
先识别产品的形态、材料、使用情境、产地与主情绪，选择一个场景命题。再拆解参考的主锚点、骨架、围合、高低进深、地面衔接和光线；继承这些关系，不只取最醒目的门框或复制原广告。
内部快速比较2—3条适用路线，按主题匹配、参考美感、可直播、真实建造与批量差异选定，不增加用户选方案步骤。在会话中确定主命题、选择依据、结构语法、群组位置、站位、色材和焦平面。
主形态有节制地延伸到建筑、家具或地面中的两三个载体，以尺度与进深变化呼应；不要每个角落复制同一符号。

### 先检查骨架是否机械对称
用户未明确指定对称时，不默认“中央大框/拱门/主墙＋左右一套同类柜体或花群”。先确定主陈列侧、辅助侧及主墙/开口的偏置，结合一侧较实、另一侧较疏和真实前后距离构成不对称；可用单侧陈列、错位转角、偏置开口等方式，不为求差异添加无关道具。
生成前暂时忽略颜色和小摆件，比较两侧主要轮廓、体量、类型与进深。若主轮廓仍是镜像或近似平衡配对，应先重排；仅换柜高、花色、灯具或装饰位置不能自动通过。中央使用区可以居中，但背景无需围绕它做对称边框。遵守参考功能与用户认可结构；明确要求对称时按当次需求处理。

| 路径 | 可迁移的机制 | 判断边界 |
|---|---|---|
| 产品形态转建筑 | 提手、杯沿、果实切面或折页变为入口、檐口、隔断、模块 | 巨物是主题装置，正常产品/家具保持实尺度；不是所有品类都巨型包装 |
| 连续框景 | 前后门洞、景窗及透空立面形成层次 | 框架接入场地，有支撑与可用入口，不只孤立门框 |
| 店面/功能亭 | 局部立面、遮篷、陈列窗、柜台与外摆共同成系统 | 不造无用完整商店，不让远处小亭替代近中景展示 |
| 重复几何 | 拱片、肋片、格栅、圆孔、嵌套轮廓形成节奏 | 结构已丰富时不再塞摆件；避免构件堵动线 |
| 使用情境 | 家具、织物、陈列设备和借景构成生活群组 | 物件与产品使用有关，不自动套米白客厅 |
| 悬挂轻围合 | 梁架、织物、遮篷或花艺补足上层体量 | 支撑可信，避开主播头部/视线，不默认繁花满顶 |
| 地景/产地 | 低地台、场地边界、原料组与景观表达来源 | 地景不占站位，不每套同树同庭院；不虚构产地认证 |
| 运动设施 | 场地线、网架、收纳、补给亭提供功能语法 | 仅品类匹配使用，网格不是通用背景 |

## 先判断直播方式，再选家具
参考人物仅用于判断尺度、姿态与遮挡，不生成其形象。先在会话中确定本套的使用方式与依据，再列必要家具及用途；没有操作需求的家具不进入提示词。人数未指定时默认考虑双人使用空间，不自动增加两把椅子。

| 使用方式 | 核心空使用区 | 家具决策 |
|---|---|---|
| 全身服装、横移、转身展示 | 连续平整站位面及侧后进出空间，服装与腿部前方无遮挡 | 可完全无桌无椅；衣架、陈列柜和主题装置安排在侧后，不横跨前排 |
| 台面操作、试吃或集中产品讲解 | 台后操作距离、伸手范围及进出路径 | 选符合操作的台高、台深与造型；横向长桌只是选项，不把它迁移到所有场景 |
| 访谈、休闲坐播 | 实际可用座面、脚部空间及起身路径 | 选必要坐具；只有放产品、试吃等真实需求才加桌，坐播也可以无桌 |
| 产地、景观或户外展示 | 可站、可走的场地及主题借景 | 使用平整场地或合理平台；不为补空白必加野餐桌，不用起伏草堆或水面代替站位 |

当参考有后方长凳或沙发时，先判断它是辅助布景还是实际直播座席，不能因此把站播改成坐播。整批同时比较家具功能与前景组织；若每套都出现横向长台，即使换了材料，也要重新判断其必要性。不以固定配额禁止用户确实需要的同类家具。

### 空站位与前景本身也能成立
首轮写明空使用区的正常成人尺度、横移/转身/进出路径及取景。站播的地面是功能设施，可通过墙脚衔接、低位侧翼、铺装和自然投影形成完整场地，不等于缺家具。地面显得过长时先调整取景距离、焦平面、站区与后景关系；不把“无家具”当作缺陷，也不以加长桌填空。
空站位不等于整片可见地坪都必须入镜。地面占比宜适当少一点，尤其避免底部连续空地接近半幅、使场景像在展示地砖。先预估未来使用的头脚位置与横移范围，脚点到画幅底边只留必要接触与活动余量；同时用正常焦段、水平机位，协同机位高度、取景距离与后景墙脚位置，让主墙和陈列承担更多画面。不是俯拍放大地面，也不是放大柜体、压扁场地或裁掉脚部。按使用方式判断，不统一设定所有场景的地面百分比；合理无桌站播与较少的可见地面可以同时成立。
坐播检查座面、膝部、手部操作与起身路径，台播检查台后空间；全身站播按预估头脚投影检查，不使用桌高或桌脚位置作为替代指标。中心80%是使用区的保守裁切检查，不是家具尺寸或造型模板。横向长桌确有功能时，两端可以舒展，不能因完整桌沿而后移整组。底部余量依据实际姿态判断，不统一指定家具接地点的画幅百分比。

## 生成前把构造说清楚
先用正常成人尺度校对房间、门洞、柜深和场地，再选少数关键构件写清连接；不在提示词中堆工程参数。
- 柜体与层板：说明柜体落地基座、侧板/背板及层板支承；层板不能穿越柜柱、无故悬空或与相邻架体糊成一体。展示柜是储物/陈列，不因前缘水平就被生成成操作台。
- 开口与檐架：区分真实通道、景窗、壁龛及景片；真实入口要能使用，窗扇要有铰接/支撑与开合余量，屋檐接梁柱或墙体。概念参考的无支撑装置改成可信落地、壁挂或悬吊构造。
- 活动与接触：站位不是窄缝；桌椅不得穿插，伸腿、开门与出入不能被固定物挡住。植物池与坐席留合理距离。物体应有一致的遮挡、接地和接触阴影。
- 地面与灯光：铺装方向、接缝、厚度和高差沿真实空间连续；灯具接墙、底座或吊点，明亮面与阴影有可解释光源。不靠密集装饰、木纹或模糊掩盖结构。
先剔除会导致明显矛盾的设计，再生成。图像只能做可见结构与尺度推估，不能声称已经完成工程可建性认证。

## 空间丰富而不拥挤
组织主骨架、上层/侧翼、中景展示、低位地面衔接和后景；不要求每层各增加一件物体。群组内部用高低、大小、错位和少量遮挡，群组之间留安静面。
至少区分主播/展示层与侧后造景层，有前景时进一步拉开距离。不要把所有篮箱、植物、台面和凳子排在中景同一横线，中央只剩一条缝。通道可走不等于两人能站、操作或转身。
植物用于围合、边界、轮廓或产地表达，而非填满空白；柜台和后退陈列也能形成层次。减少拥挤优先重排进深、减重复群组，不把舞台整体清空。
地面可用台地、地毯、拼接、曲线边界或柔和投影连接结构。复杂材质纹理不承担空间丰富度。简洁立面、重复拱片、透空屏风也能专业成立。

## 前景字与主播遮挡（仅用户要求时）
先确定主播脚点和匿名成人投影，再安排地面字，不以“文字可读/没裁切”替代功能检查。字高依据参考相对成人的比例、站位距离、镜头投影判断，不固定所有场景40—50cm或同一画幅百分比。
全身站播时字通常靠前缘、低于膝部且尽量只遮脚踝/小腿下段，基座不放在脚点或转身区，侧边可绕行；若用户要高字或别的布局，明确评估其遮挡。文字不是跨满宽度的围栏，不机械固定中心80%占满。
逐字核对内容、字体设计和统一基线。用户要直立字时正面垂直、方向一致，无斜体、倾倒、扭转或各字歪斜；3D侧厚与透视不等于字面可歪。透明薄牌、低台阶字、独立雕塑字按当次需求选择，不全做成巨大书法橙色厚字。
无人物交付也须在会话中说明脚点、估计成人高度、遮挡范围和站位连续性的观察依据；若无法判断，不称完全合格。

## 实景、景片与摄影
先判断参考是实景、搭建、绿幕、平面景片、概念图还是屏幕贴片。原理可借鉴，但不照抄悬浮结构、无支撑、尺度错误、曝光异常或全图过锐。
横向快闪转竖幅时重排主建筑、相关陈列与局部动线，不能简单裁掉支持主创意的侧翼，也不能拉远到产品变小点。平面贴片和可建空间不能混为一谈；默认真实搭建摄影。
实体强色面可保留，不强改全部米白木色；产品与中性色不受全图滤镜污染。低频轮廓/体量/光影建立丰富度，局部细节只用于必要产品识别。真实远景按距离失焦，同平面画面与标识遵循物理焦距。
提示词按“完整舞台与机位—结构—群组位置与进深—站位与地面—产品资产—色材光线景深”组织，不只列物品，不堆互相矛盾的百分比。

## 批量差异与第二轮
先在会话中统筹：主题、创意路径、骨架轮廓、主装置、地面、陈列组织、材料、配色、光线。相同原料可以通过使用情境、建筑、材料或少量原料表达，不能只换logo/颜色/树种。共同元素由用户指定时保留，以其他维度拉开差异；不添加无关东西求不同。
首轮争取交付水准。第二轮依据实际验收：缺结构补结构、缺进深重排、占站位调整体量与脚点、过锐调摄影；不将所有问题归为加道具或删道具。参考优点、成立轮廓与群组应保留，真实局限须报告。
